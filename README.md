# Mashrur Shitab | Business Analytics Portfolio

Hi, I am Mashrur Shitab. This GitHub profile is used to showcase portfolio projects in business analytics, data analysis, machine learning, SQL database design, and decision-support reporting.

## Featured Projects

### [LuminaTech Sales Forecasting & Customer Churn Analytics](luminatech-sales-churn-analytics/)

An end-to-end analytics case study using Python, pandas, statistical testing, regression analysis, sales prediction, and leakage-aware churn modelling for a retail lighting business.

Highlights:

- Cleaned and analysed 1.97M transaction rows.
- Built sales, profitability, customer acquisition, and operational efficiency insights.
- Improved the churn workflow from suspicious perfect accuracy to a realistic time-based validation approach.
- Selected a Random Forest churn model with 0.885 accuracy, 0.896 recall, 0.833 F1-score, and 0.953 ROC-AUC on a later test snapshot.
- Created executive and technical documentation for recruiter and stakeholder review.

### [Pulse Fitness SQL Analytics Platform](pulse-fitness-sql-analytics-platform/)

A full SQL database design and analytics project for a simulated multi-location fitness business, covering relational modelling, attendance tracking, revenue analysis, member retention, trainer performance, class utilisation, and operational efficiency.

Highlights:

- Designed an 11-table MySQL schema with primary keys, foreign keys, constraints, and indexes.
- Added attendance-aware class modelling with FitnessClass, ClassSession, ClassEnrollment, and ClassAttendance.
- Built a 600-member simulated dataset with payments, visits, class attendance, and personal training activity.
- Created 12 SQL analysis queries from basic aggregation to advanced CTEs, scoring logic, and scorecards.
- Exported CSV results and wrote management-facing recommendations.
