# Business Rules

- Each member belongs to one membership type.
- Each member is registered at one home gym location.
- A membership type can be assigned to many members.
- A gym location can have many members, trainers, visits, class sessions, and personal training sessions.
- A trainer is assigned to one home gym location.
- A fitness class can have many scheduled class sessions.
- A class session is conducted by one trainer.
- A class session occurs at one gym location.
- A member can enrol in many class sessions.
- A class session can have many enrolled members.
- Class enrollment records booking intent.
- Attendance is recorded separately from enrollment.
- A member may enrol but not attend.
- Attendance outcomes are Present, Late, Absent, or No-show.
- Payment records track successful and unsuccessful transactions.
- Personal training sessions link members, trainers, and locations.
- Facility visits track member check-ins and check-outs by location.
